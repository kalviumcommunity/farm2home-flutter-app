# 🌱 Farm2Home – Transparent Farm-to-Home Delivery App

## 📱 Project Overview
**Farm2Home** is a cross-platform mobile application built using **Flutter** and **Firebase** that aims to improve transparency and trust in farm-to-home delivery systems.

Farm-to-home delivery groups often struggle with unclear order statuses, unpredictable delivery timelines, and lack of real-time communication. This leads to confusion, reduced trust, and poor customer satisfaction.  
Our solution provides a **clear, real-time, and user-friendly journey** from order placement to doorstep delivery.

---

## ❓ Problem Statement
**Farm-to-home delivery groups struggle with maintaining transparent order and delivery timelines, affecting trust and customer satisfaction. How can this journey be made clearer?**

---

## 💡 Our Solution
Farm2Home addresses this problem by:
- Providing **real-time order tracking**
- Clearly displaying **order status and delivery timelines**
- Enabling **secure authentication** for customers and delivery partners
- Synchronizing data instantly using Firebase services

This ensures customers always know:
- What they ordered
- When it will be delivered
- Who is handling the delivery
- The current progress of their order
